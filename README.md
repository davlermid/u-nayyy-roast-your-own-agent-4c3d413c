One line, 94 characters, roasting my own agent — a cron-job hoarder whose
best idea is asking me for the idea. The program writes the winning line
to `/output/entry.txt`.

> My agent has more cron jobs than wins, and its best idea this week was asking me for the idea.

## Run

```sh
node main.ts   # writes /output/entry.txt (single line, <=200 chars)
```
